# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Esperamos un trato respetuoso, inclusivo y profesional en issues, pull requests y cualquier otro espacio del proyecto.
Los comportamientos inaceptables se pueden reportar de forma privada a través del
[aviso privado de GitHub](https://github.com/DannyGalvan/Plantilla_NET_React_TypeScript/security/advisories/new)
o al mantenedor del repositorio. Todos los reportes se revisan con confidencialidad.
