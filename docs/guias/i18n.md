# i18n

> Cómo agregar idiomas, namespaces y traducciones en backend y frontend.

## Backend

`IStringLocalizer<T>` con `ResourceManagerStringLocalizer` (built-in de
ASP.NET Core). Los archivos de recursos viven en
`src/Host/Project.Api/Resources/{culture}.resx`.

```csharp
public sealed class MyService(IStringLocalizer<MyResource> localizer)
{
    public string Greet(string userName) =>
        localizer["Greeting", userName];
}
```

Para agregar un idioma:
1. Crear `Resources/es.resx` y `Resources/en.resx` con las mismas claves.
2. Configurar `services.AddLocalization(o => o.ResourcesPath = "Resources")`.
3. Configurar `RequestLocalizationOptions` con los `SupportedCultures`.

Validación: `dotnet build` falla si falta una clave en alguna `resx`.

## Frontend

`react-i18next` + `i18next-browser-languagedetector`. Los archivos viven en
`src/shared/i18n/{locale}/common.json` + `src/modules/{module}/i18n/{locale}.json`.

```ts
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  return <h1>{t('common.welcome')}</h1>;
}
```

Los módulos declaran sus namespaces via `ModuleManifest.i18n`:

```ts
i18n: {
  es: () => import('./i18n/es.json'),
  en: () => import('./i18n/en.json'),
}
```

El `bootstrap` (en `app/main.tsx`) registra cada namespace antes de
montar el router. Selector de idioma en el `UserMenu`.

## Locale por defecto

`LocalizationSettings.Locale` (configurado vía `/platform/config` o
settings en cascada). El bootstrap lo aplica al `i18n` antes de cargar
el primer componente.

## Currency y formato

`LocalizationSettings.Currency` + `Intl.NumberFormat` para moneda.
`LocalizationSettings.DateFormat` + `Intl.DateTimeFormat` para fechas.
`useSettings('localization')` los expone como hook de React.

## Pluralización

`i18next` soporta claves plurales:

```jsonc
{
  "cart": "{count, plural, one {# item} other {# items}}"
}
```

```ts
t('cart', { count: items.length });
```

## Cómo agregar un nuevo idioma

1. Backend: agregar `Resources/fr.resx`. Actualizar
   `SupportedCultures` en `Program.cs`.
2. Frontend: crear `src/shared/i18n/fr/common.json` (clonar de `es`).
3. Agregar `'fr'` al selector del `UserMenu`.

## Testing

`Project.Application.UnitTests` incluye tests para el `FilterParser`
que verifican patrones con texto en español. Cuando agregues i18n en
backend (Fase 7 slice 2), los tests de validación de recursos cubren
que cada `IStringLocalizer[key]` retorna valor en `es` y `en`.
